# HabitFlow iPhone Web-App

Diese Version ist für die Nutzung auf dem iPhone als Web-App vorbereitet.

## Warum nicht direkt aus „Dateien“?
iOS zeigt lokale HTML-Dateien in der Dateien-Vorschau an. Dabei wird die JavaScript-App nicht zuverlässig als normale Website ausgeführt. Deshalb muss HabitFlow über eine HTTPS-Webadresse geöffnet werden.

## Empfehlung
Die Dateien können z. B. über GitHub Pages veröffentlicht werden. Danach die URL in Safari öffnen und „Zu Home-Bildschirm hinzufügen“ -> „Als Web-App öffnen“ wählen.

Die Habit-Daten werden weiterhin lokal im Browser gespeichert.
